# StudyVerse

StudyVerse は、PIN と教室コードを入口にした、スマートフォン優先の**独立型**学習アプリです。OAuthや外部アカウントへのログインには依存せず、サイト固有の全体管理者パスワードと教室PINで認証します。宇宙テーマの操作空間に、単語帳、カード練習、テスト、タイマー、学習カレンダー、ミッション、教室管理の導線を備えます。

## 起動方法

依存関係をインストールした後、開発サーバーを起動します。

```bash
pnpm install
pnpm dev
```

型検査、単体テスト、プロダクションビルドは以下で実行できます。

```bash
pnpm check
pnpm test
pnpm build
```

## 初期操作

初期画面では、4桁のPINと教室コードを入力します。PINはブラウザのローカルストレージへ保存せず、サーバー側でソルト付きハッシュとして検証します。ログインすると、12時間で失効するHTTP専用セッションCookieが発行されます。教室コードは手入力に加え、対応ブラウザではQRコードのカメラ読取が利用でき、権限拒否・非対応時には必ず手入力へ戻れます。

| 領域 | 現在操作できること | データ連携の状態 |
| --- | --- | --- |
| ホーム | 学習概要、カレンダー詳細、タイマー、各学習画面への遷移 | タイマーは画面内で継続します。 |
| 単語帳 | 英単語／漢字の切替、単語帳作成、単語追加、発音 | 画面上の教材編集は即時反映されます。 |
| 単語カード | 練習、フリップ、覚えた／復習、入力テスト、結果 | 操作フローを実装済みです。 |
| 管理画面 | 教室、利用者、教材、配信、予定の管理導線 | 全体管理者と教室管理者の範囲をサーバー側で判定します。 |

## データモデルとデータ分離

データベースには、`classrooms`、`studentProfiles`、`pinSessions`、`pinLoginAttempts`、`wordbooks`、`vocabularyWords`、`studyRecords`、`focusSessions` を用意しています。教材は本人限定、教室公開、全体公開の範囲を持ち、取得時に本人・教室・公開範囲を判定する構成です。PIN本体はソルト付きハッシュで保存し、検索には別のサーバー秘密値を用いた固定長ハッシュを使用します。認証失敗は教室コードと接続元ごとに15分間で5回までに制限されます。

マイグレーションを新規環境に反映する場合は、`drizzle/schema.ts` から SQL を生成し、内容を確認してからDBに適用してください。

```bash
pnpm drizzle-kit generate
```

## 環境変数と外部連携

プラットフォームが自動注入する認証、DB、ストレージ、AI向けの環境変数はコードに直接記録しません。本番で次の機能を有効にする際は、サーバー側の連携層から利用してください。

| 連携 | 必要になる設定 | 接続前の挙動 |
| --- | --- | --- |
| 漢字のAI採点 | 画像入力対応のAI連携 | 手書き答案の確認フローを保ち、再試行を案内します。 |
| モンスター画像 | S3互換ストレージ | 画像登録導線を表示し、ファイル本体はDBに保存しません。 |
| QR読取 | ブラウザのカメラ権限 | 権限を求め、拒否時は手入力を維持します。 |

AI連携を利用する場合は必ずサーバー側から実行し、構造化出力を検証してから問題・採点結果に反映します。外部連携が失敗した場合は、内部エラーをそのまま表示せず、日本語の再試行・設定案内に変換します。

## 管理者の初期設定

最初に、入口画面の「管理者の初期設定」からサイト固有の全体管理者パスワードで認証し、教室名・教室コード・オーナー表示名・4桁PINを作成します。全体管理者のセッションはサーバー側で8時間に制限され、ログアウトで失効します。PINは作成後に表示できないため、安全な経路で管理してください。先生は自教室の教材、予定、お知らせを管理し、生徒は本人の学習と所属教室で公開された教材だけを利用します。全体管理者のみが教室を横断して閲覧・絞り込みできます。

## 運用上の注意

外部連携を導入する場合は、学校・組織の運用ルールに合わせて教員レビューを行ってください。QR読取はHTTPSとカメラ権限を必要とします。利用者数が増える環境では、認証試行の監査とPIN再発行の承認手順を定期的に見直してください。
