# StudyVerse 実装仕様メモ

## 実装の前提

本プロジェクトは、添付仕様の機能・情報設計・宇宙を題材とした操作感を**独自のコードベースとして**実装するものです。既存サービスのロゴ、画像、認証情報、利用者データは取り込みません。外部AI、ニュース、画像ストレージが未設定の場合は、機能を無言で失敗させず、利用者が取るべき行動を案内します。

## 初期実装の画面一覧

| 区分 | 画面・状態 | 主な目的 |
| --- | --- | --- |
| 認証 | PINログイン | 4桁PINと教室コードの入力・検証 |
| 学習 | ホーム | 学習状況、カレンダー、タイマー、StudyJournalへの導線 |
| 学習 | 単語帳 | 英単語／漢字の教材一覧と編集・検索 |
| 学習 | 単語カード | 練習設定、フリップ、スワイプ／ボタン回答 |
| 学習 | テスト | 出題、回答、結果、再挑戦 |
| 学習 | StudyJournal | 難易度選択、生成案内、履歴 |
| 学習 | モンスター・ミッション | 学習を補助する進捗・達成画面 |
| 管理 | 管理画面 | 教室、利用者、教材、お知らせ、予定の管理導線 |
| 共通 | プロフィールと設定 | 表示設定、PIN、所属教室、ログアウト導線 |

## データモデルの方針

教室と利用者を明確に分け、学習データ、私用教材、予定、回答履歴は利用者に紐付けます。共有教材とお知らせには、全体公開・教室公開・本人限定を区別する公開範囲を持たせます。PINは平文では保存せず、教室識別子と組み合わせて検証する設計とします。タイムスタンプはUTCで保存し、画面表示でローカル時刻に変換します。

## 権限の方針

| 権限 | 閲覧・操作範囲 |
| --- | --- |
| 全体管理者 | 全教室の横断管理、全体公開コンテンツ、利用者の絞り込み |
| 先生 | 自教室の生徒、教材、お知らせ、イベント、テストの管理 |
| 生徒 | 自身の学習、本人限定教材、所属教室で公開されたコンテンツの閲覧 |

## 未確定事項

AIによる記事・漢字採点、当日ニュース取得、教師向けQRの発行、画像アップロードの本番接続には、利用サービスと必要なキーの設定が必要です。初期版では、接続前でも画面と失敗時案内が成立するように実装し、接続先が決まり次第置き換えられる構造を維持します。

## データモデル

| エンティティ | 主な属性 | 分離・参照の原則 |
| --- | --- | --- |
| 教室 | `code`、`name`、`teacherUserId`、`settings` | 教室コードを一意にし、先生は自教室のみ管理できます。 |
| 学習者プロフィール | `userId`、`classroomId`、`pinHash`、`displayName`、`role` | PIN検証は教室識別子と組み合わせ、平文を保存しません。 |
| 単語帳 | `ownerUserId`、`classroomId`、`visibility`、`language`、`title` | 本人限定・教室公開・全体公開を明示して取得時に判定します。 |
| 単語 | `wordbookId`、`front`、`back`、`reading`、`source` | 単語帳に従属し、CSV取り込み元も記録できます。 |
| 学習記録 | `userId`、`wordId`、`mode`、`result`、`answeredAt` | SRS、定着率、連続学習日数の集計元です。 |
| 学習セッション | `userId`、`startedAt`、`endedAt`、`focusSeconds` | タイマーの時刻基準継続と日別集計に利用します。 |
| StudyJournal記事 | `userId`、`subject`、`level`、`article`、`questions`、`createdAt` | 生成履歴と採点結果を本人限定で保持します。 |
| お知らせ・予定 | `classroomId`、`visibility`、`publishedAt`、`expiresAt` | 全体公開と教室限定を取得クエリで必ず区別します。 |
| ミッション・報酬 | `userId`、`cycle`、`progress`、`claimedAt` | 日次・月次のリセットと未受取失効を判定します。 |
| モンスター育成 | `userId`、`speciesId`、`stage`、`studySeconds`、`evolvedAt` | 20時間区切りの進化条件と育成履歴を保持します。 |

## API境界

| 領域 | 操作 | サーバー側の確認 |
| --- | --- | --- |
| 認証 | PINログイン、教室照合、QRコード読取結果の反映 | 4桁形式、教室存在、失敗回数、PINハッシュ比較 |
| 教材 | 単語帳一覧・作成・更新・削除、CSVの事前検証と反映 | 所有者・教室・公開範囲、最大3,000行、行単位の入力検証 |
| 学習 | 練習結果、テスト結果、タイマー、SRS予定の保存 | 当該教材への閲覧権、UTC時刻、完了条件 |
| Journal | 記事生成、履歴取得、回答採点 | 本人限定、二重生成防止、AI応答のスキーマ検証 |
| 配信 | お知らせ、イベント、おすすめテストの作成・取得 | 全体管理者／先生の権限、公開対象、配信期間 |
| 進捗 | ミッション受取、モンスター進化、持ち物の取得 | 未受取・達成済みの整合性、教室をまたぐ参照の禁止 |

## 状態遷移

| 操作 | 開始状態 | 主な遷移 | 終了状態 |
| --- | --- | --- | --- |
| PINログイン | 未認証 | 入力中 → 検証中 → 成功／入力エラー／利用制限 | 学習ホームまたは再入力案内 |
| カード練習 | 確認画面 | 通常・逆・ランダム選択 → カード表示 → 回答記録 | 結果表示、ミッション進捗更新 |
| テスト | テスト確認 | 設定 → 出題 → 回答 → 採点 → 次問 | 完了結果、誤答のみ再挑戦、または中断 |
| Journal生成 | 生成前 | 条件選択 → 生成待機 → 構造検証 | 記事・問題表示、失敗時再試行案内 |
| ミッション報酬 | 進捗中 | 達成 → 受取可能 → 受取処理 | ポイント加算済み、日次／月次で更新 |
| モンスター進化 | 育成中 | 学習時間蓄積 → 進化可能 → 明示的な進化実行 | 次の段階、または新しい生物選択 |

## 実装フェーズ

最初にPINログイン、ホーム、教材・カード練習、テスト、タイマー、教室別データ取得の土台を実装します。次にStudyJournal、管理者配信、カレンダー、ミッション、モンスター育成へ拡張します。外部AI・ニュース・画像ストレージの接続は、サーバー側の単一の連携層を経由し、接続前には利用者向けの設定案内を表示する方針です。
