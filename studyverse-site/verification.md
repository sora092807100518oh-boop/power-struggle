# 独立認証の実画面検証記録

開発プレビュー上で、サイト固有の全体管理者パスワードを使った独立認証を確認しました。

| 確認項目 | 結果 |
| --- | --- |
| 初期設定の認証画面 | 「外部アカウントとの連携は不要です」と表示され、サイト固有パスワードの入力欄が表示されることを確認。 |
| 管理者ログイン | 正しいパスワード入力後、通常の管理画面へ自動遷移することを確認。 |
| PIN再発行導線 | 管理画面の「利用者」タブに、対象利用者の選択・新4桁PIN・再発行操作が表示されることを確認。 |
| 管理者ログアウト | プロフィールのログアウト後、入口画面へ戻り、「ログアウトしました。」と表示されることを確認。 |

サーバー側では、独立管理者のセッション照会と失効、教室作成、オーナーPIN発行、PIN再発行、権限不足時の拒否を自動テストで確認しています。
